# GPA Calculator

A small web app that calculates your semester GPA from subjects, marks and credit hours.

## Features

- Add subjects with marks (0–100) and credit hours
- Marks converted to grade points and letter grades with conditionals
- Weighted GPA: sum of (grade points × credit hours) ÷ total credit hours
- Remove a single subject or clear all, with the GPA updating instantly
- Simple validation for empty or out-of-range inputs

## Tech used

- HTML + Bootstrap 5 (layout and styling)
- CSS (small custom touches)
- Vanilla JavaScript — `let`/`const`, functions, conditionals, and a loop

## How to run

Open `index.html` in any browser. No build step or server needed.
